# Architecture: CMS Pipelines → Rust

## Design rules (Hartmann)

1. **Stages never call each other.** They call dispatcher services on `StageCtx`: `read`, `write`, `commit`, `delay_record`, `wait_until`, `stop_external_waits`, `short`, `callpipe`.
2. **Records**, not byte streams, are the unit of transfer (`pipe_core::Record`).
3. **At most one record in flight** per connection unless a stage explicitly buffers (`BUFFER`, `SORT`).
4. **Drain-biased scheduling:** consumers that can read are preferred over producers.
5. **Device drivers vs filters:** disk/command/console live in driver stages; filters only transform records.

## Type map

| CMS concept | Rust |
|---|---|
| Record | `pipe_core::Record` |
| Stream number | `pipe_core::StreamId` |
| Stage | coroutine running a `StageFn` / `FnOnce(&mut StageCtx)` |
| Dispatcher | `pipe_core::Dispatcher` via `PipelineBuilder::run` |
| PIPE specification | `pipe_parser::parse_pipeline` |
| Built-in program | factory in `pipe_stages::StageRegistry` |
| CALLPIPE | `StageCtx::callpipe` + connectors |
| REXX stage | `pipe_rexx` (`READTO` / `OUTPUT` / `CALLPIPE` / …) |

## Coroutine model

Each stage runs on a **stackful coroutine** (`corosensei`). When `read`/`write`/`commit` cannot complete, the stage **suspends**; the dispatcher resumes another ready stage. A thread-local holds the current `Yielder` so `StageCtx` stays easy to call.

## Multi-stream labels

```text
(ENDCHAR ?) literal a|literal b | L: locate /a/ | console ? L: | console
```

- First `L:` defines the stage and its primary streams.
- Later `L:` occurrences attach secondary/tertiary streams of that same stage instance.

## CALLPIPE / ADDPIPE

Nested specifications may start/end with IBM `*:` connectors (bare `*` still
accepted as a synonym):

- Leading `*:` — feed nested pipeline from the caller’s selected input.
- Trailing `*:` — drain nested output to the caller’s selected output.
- Also recognized: `*.input:`, `*.output:`.

v1 implements connector CALLPIPE in **buffering** mode (read all → run nested → write all), which is record-correct and sufficient for REXX filters. Streaming bridges can replace this later without changing the stage API. Buffering cannot hand an unconsumed nested record back to the caller, so TOLABEL / WHILELABEL leftover (p.559 / p.596) stays subset until Phase 4 Streaming CALLPIPE.

## REXX / Regina

`pipe-rexx` runs `.rexx` stages with this preference order:

1. **Regina** (user-installed) — dynamically load `regina.dll` / `libregina.so` / `libregina.dylib`, register ADDRESS `PIPELINE`, `RexxStart` the script file.
2. **Subset interpreter** — if Regina is not found or cannot load.

Discovery env vars: `PIPE_REGINA`, `REGINA`, `REGINA_HOME` (file or directory). Also searches PATH, the `pipe` executable directory, and common install prefixes.

The Windows zip from `scripts/package-windows.ps1` places `regina.dll` next to `pipe.exe` so that executable-directory search succeeds. See [packaging.md](packaging.md).

Pipeline subcommands use **IBM names only** (ADDRESS `PIPELINE` / subset statements):

| Subcommand | Meaning |
|---|---|
| `READTO var` | Read one record; RC=12 at EOF |
| `OUTPUT` | Write a record (command string after verb) |
| `CALLPIPE` | Nested pipeline |
| `ADDPIPE` | Attach nested network (v1 ≈ CALLPIPE) |
| `SHORT` | Sever selected streams |
| `SELECT INPUT/OUTPUT n` | Choose stream |
| `COMMIT n` | Commit level (Regina path) |
| `PEEKTO` | Not yet |

## Fidelity vs IBM

For features we implement, match **IBM CMS Pipelines** (Author’s Edition / z/VM reference) — names, record semantics, dispatcher rules. Do not invent alternate spellings (e.g. no `WRITETO`; the write subcommand is `OUTPUT`). Out-of-scope items stay omitted rather than approximated under a different name; track them in [`builtins-roadmap.md`](builtins-roadmap.md).

| STRFIND / STRNFIND | Full stages per Author's Edition 1.1.11 pp.349 / 438 (STR branch of the FIND/NFIND railroads) and the STRxxxxx family p.534. Type: Selection. Syntax (diagrams all-caps): `STRFIND [ANYcase] delimitedString` / `STRNFIND [ANYcase] delimitedString`. No verb prefix (`strfin` / `strnfin` are unknown). A delimited string is required (pair / hex / binary, p.194). `ANYCASE` min 3 (shared `is_anycase`; synonyms `CASEANY` / `IGNORECASE` / `CASEIGNORE`, p.350 Note / p.439 Note 2). Invented operands and `ANYCASE` after the dstring are rejected. Matching is the same XEDIT FIND/NFIND logic as FIND/NFIND; `ANYCASE` ignores case for characters other than blank (don't-care) and underscore (required blank). A null dstring (`,,` / `//`) matches any record. Streams, record delay, premature termination, and commit match FIND. No dispatcher changes. **Ambiguity — ANYCASE minimum:** the railroad is `ANYcase` (min 3) and STRFIND has no `ANYOF`. Shared `is_anycase` is min 3 (`any` accepted, `an` rejected). STRIP/SPLIT/CHOP/JOINCONT/LOCATE keep min 4 because `ANYof` wins at 3 (or the railroad is `ANYCase`). **Ambiguity — STRLITERAL:** p.412/534 adds `PREFACE` / `APPEND` / `CONDitional` / `IFEMPTY` that LITERAL does not implement; left Phase 6. Portable ASCII: hex/binary are raw bytes (`x02` is X'02'; the book's `xf1f2f3` example is EBCDIC). |
| FRLABEL / TOLABEL / WHILELABEL | FRLABEL full; TOLABEL / WHILELABEL subset per Author's Edition 1.1.11 pp.353–354 (FRLABEL), 559–560 (TOLABEL), 596–597 (WHILELABEL). Type: Selection. Syntax (diagrams all-caps): `FRLABEL [string]` (synonym `FROMLABEL`, p.353 Note 1), `TOLABEL [string]`, `WHILELABEL [string]`. No verb prefix (`frlab` / `tolabe` / `whilelab` are unknown). The string starts after exactly one blank (same remainder scanner as LITERAL/FIND). Matching is a **literal prefix** (not XEDIT FIND don't-care / underscore): a null string matches any record; a record shorter than the string does not match. FRLABEL copies records before the first match to secondary (or discards them) and then the matching record plus the rest to primary (INCLUSIVE default). TOLABEL copies records before the match to primary; EXCLUSIVE default leaves the match off primary and, if secondary is defined, copies the remaining input including the match there after severing primary output. WHILELABEL copies while records match to primary, then severs primary and copies the remaining input to secondary. Streams: primary input; secondary streams may be defined; secondary input must not be connected. Record delay: strictly does not delay — `peek`, write to exactly one connected output, `read`. Premature termination when **no** output stream is connected. Commit −2 then 0: auto-commit to 0. No dispatcher changes. **Ambiguity — EXCLUSIVE/INCLUSIVE on the plain verbs:** the railroads put those keywords only on the STR branch (pp.353, 559). On FRLABEL/TOLABEL they are remainder text, not keywords. **Ambiguity — IBM SHORT splice:** FRLABEL shorts primary in to primary out after the match (p.353); TOLABEL/WHILELABEL short remaining input to secondary (pp.559, 596). Our `short` severs. Copy of remaining records is the splice stand-in (same as TAKE). When the destination is not connected the trigger is peeked and not consumed by the stage; `short_input` then drops the slot so a standalone producer is not parked. Buffering CALLPIPE cannot hand that leftover back to the caller, so TOLABEL / WHILELABEL are subset: matching record not left in the pipeline for the CALLPIPE caller to re-read (needs streaming CALLPIPE, Phase 4, postponed), p.559 / p.596. **Ambiguity — extra inputs:** tertiary and higher inputs are rejected. **Ambiguity — commit −2:** auto-commit to 0. Portable ASCII: prefix compare is bytes (hex dstrings are raw). The p.596 `'02'x \|\| 'ESD'` sample is REXX concat of EBCDIC X'02' with ESD; tests use `/abc/` and `x02`. |
| STRFRLABEL / STRTOLABEL / STRWHILELABEL | Full stages per the STR branches of FRLABEL (p.353), TOLABEL (p.559), WHILELABEL (p.596 `STRWHILElabel`), and the STRxxxxx family p.534. Syntax: `STRFRLABEL [ANYcase] [EXCLUSIVe \| INCLUSIVe] delimitedString` (synonym `STRFROMLABEL`); `STRTOLABEL` the same; `STRWHILELABEL [ANYcase] delimitedString` (min 8: `STRWHILE`). A delimited string is required. `EXCLUSIVe` / `INCLUSIVe` min 8; FRLABEL default INCLUSIVE, TOLABEL default EXCLUSIVE (p.353 / p.559). `ANYCASE` min 3 (shared helper; `any` accepted, `an` rejected) with the documented synonyms. Invented operands, `EXCLUSIVE` on STRWHILELABEL, and keywords after the dstring are rejected. Operation is the corresponding plain stage with caseless prefix compare when ANYCASE is specified. No dispatcher changes. |

## Pipeline fixtures

End-to-end specifications live in `tests/pipelines/*.pipefix`: a PIPE string plus
the records (or error substring) it must produce. `CONSOLE` is rewritten to an
in-memory collector; the runner does not spawn the CLI. `examples/README.md`
`pipe "…"` lines are harvested into `readme-harvest.pipefix`; a completeness test
fails if a README example is missing. See `tests/pipelines/README.md`. This is
not a cartesian product of operands — book and README pipes, plus documented
rejects.

## TRACE

`(TRACE)` in the options group, or CLI `--trace` / `-t`, enables `TraceConfig` on the dispatcher. Events: dispatcher start/end, stage start/end, READ/WRITE (length + short preview), COMMIT request/wait/proceed, SHORT, DELAY, STOP external waits, CALLPIPE enter/exit. Output defaults to stderr with a `PIPE TRACE:` prefix; tests may use `TraceConfig::capture`.
